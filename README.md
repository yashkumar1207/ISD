# Bowling Night

A small 3D bowling game built with Unity primitives and C#. The game creates its lane, ball, pins, camera, and controls at runtime.

## Open the project

Open this folder in Unity 6000.6.3f1, then press Play in the SampleScene.

## Controls

- A / D: aim left or right
- W / S: adjust power
- Space or the on-screen ROLL button: roll

The game tracks knocked pins across ten frames and reports strikes and spares. No external models are required.
